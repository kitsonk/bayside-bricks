## Defect found and fixed during verification

Setting `PRODUCTION_URL` made the `Smoke test the public URL` step run for the
first time. It failed on `/robots.txt` (`status 200 != 404`) in run 43367778223,
twice.

Cause is platform, not app: `/robots.txt` is Cloudflare's managed file on every
host the zone fronts, and the body it rendered differed by edge — the 1248-byte
content-signal document from this machine (15 consecutive requests) and from the
workers.dev host in the same runner job, but an empty `200` from the custom
domain in both attempts of that run. The app has no `/robots.txt` route.

Fixed in [PR #11](https://github.com/kitsonk/bayside-bricks/pull/11): any 2xx on
that path is a SKIP that prints status, byte count and shape; only a non-2xx
fails. `docs/ci-cd.md` §7.2 records it. By the next run the edge was serving the
content-signal document again, so the empty body was a short-lived rendering
during/after the deployment, not a persistent state.

## Observations, not defects

- **`Always Use HTTPS` is off on the zone.** `http://bricks.kitandsimon.com/`
  answers `200` over cleartext with no `Location` and no HSTS. No credentials are
  collected on this page, but the setting is a one-click improvement and affects
  the whole zone. Not changed here — it is a zone-wide decision.
- **The apex is not proxied.** `kitandsimon.com` resolves to a single DNS-only
  address, the GoDaddy origin (`160.153.0.160`); it is not on the Worker and was
  not part of this cutover. §7's "apex resolves to two Cloudflare anycast
  addresses" described an expectation that does not match the zone and has been
  corrected.
- **Mail round trip not performed.** MX records are present and unchanged, but a
  send/receive test needs a mailbox; that remains a human check.
- **Deploy on every `main` push.** `ci-cd.yml` has no `paths` filter, so even a
  docs-only merge redeploys production. Harmless (idempotent, ~30s) but it means
  documentation changes consume a deployment; worth a `paths` filter if the
  version list gets noisy.
